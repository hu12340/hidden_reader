# HiddenReader 首版需求

## 1. 产品目标与范围

HiddenReader 是一款面向 Windows 11 的本地小说阅读软件。普通模式用于管理书库、浏览目录和搜索正文，极简模式用于把小说正文浮在其他应用上方。

首版提供图形界面，只支持从本机导入 TXT 小说。导入、阅读、搜索、设置与状态恢复均可在断网时使用。翻译和全局翻页快捷键不纳入首版。

## 2. 本地书库

- 支持从本地选择 TXT 文件导入，并在书架上列出已导入的小说。打开书架中的小说时，从该书上次的阅读位置继续。
- 导入时，软件将 TXT 复制到自己管理的本地书库。导入完成后，即使原文件被移动、改名或删除，书架中的副本仍可阅读。
- 从书架移除小说时，删除对应的书库条目和副本，保留原文件。

## 3. 正文、目录与搜索

- **章节目录**　从 TXT 中识别章节标题，点击章节可跳到该章开头。没有可识别章节的小说仍可打开、翻页、跳页和搜索。
- **翻页与跳页**　支持前后翻页和跳到指定位置。普通模式和极简模式下，左键单击正文任意位置都翻到下一页。阅读窗口有焦点时，`←` 翻上一页，`→` 翻下一页。其他软件有焦点时，方向键照常由当前软件处理。
- **鼠标操作**　翻页由单击触发。拖动选字、移动浮窗或缩放窗口时，松开鼠标不会翻页。
- **全书搜索**　搜索当前小说的全部正文。结果列表显示命中位置附近的文字，点击结果跳到对应位置并高亮命中文字。
- **窗口自适应**　普通窗口和极简浮窗均可自由缩放。窗口尺寸改变时，界面适配可用空间，正文重新换行和分页，原阅读位置仍在调整后的页面中。阅读进度以正文位置为准，避免页码随尺寸变化而导致恢复错位。

## 4. 极简浮窗与透明度

- 从普通模式可切换到极简模式。极简模式隐藏标题栏、书架、目录和工具栏，只显示正文，并保留尽量窄的缩放热区。
- 进入极简模式时默认置顶。置顶可单独开关，关闭后仍可继续使用极简界面。
- 浮窗可移动和缩放。即使边框透明，仍能从边缘调整大小。极简模式提供可达的操作入口，用于调整设置或恢复普通模式。
- 阅读背景与边框的不透明度可分别调节，范围为 `0%`（完全透明）至 `100%`（完全不透明）。背景和边框的设置不改变正文的不透明度。背景完全透明时，仍可单击正文翻页。

## 5. 阅读进度与启动恢复

- 翻页、目录跳转、跳页和搜索跳转后自动保存阅读位置。每本小说保留各自的进度。
- 下次启动直接恢复上次阅读的小说、正文位置和界面模式。上次以极简浮窗退出时，直接打开极简浮窗，跳过书架。
- 恢复浮窗的位置、大小、不透明度和置顶设置。若原显示器已断开，恢复后的窗口应位于可用屏幕的可见范围内。
- 首次启动，或上次的小说已被移除或无法打开时，进入书架。

## 6. 开发默认值

以下细节用于指导首版实现，可在开发中调整。

| 项目 | 初始方案 |
| --- | --- |
| 导入入口 | 文件选择和拖放均可导入。 |
| TXT 编码 | 自动识别常见编码，优先支持 UTF-8 和 GB18030。遇到乱码时可手动切换编码。 |
| 章节识别 | 优先识别单独成行的常见中文标题，如「第一章」和「第 12 章」。 |
| 跳转入口 | 支持从章节目录跳转，或在跳页面板中输入当前排版的页码或全书百分比。 |
| 搜索操作 | 阅读窗口有焦点时按 `Ctrl+F` 打开搜索。结果包含命中上下文，可返回搜索前的位置。 |
| 浮窗操作 | 右键正文打开浮窗菜单，`Ctrl` 加左键拖动移动浮窗，有焦点时按 `Esc` 恢复普通模式。 |
| 初始排版 | 默认字号、行距和最小窗口尺寸根据窄浮窗下的可读性确定。 |

## 7. 首版验收场景

| 场景 | 预期结果 |
| --- | --- |
| 断网后导入并阅读 TXT | 小说可导入书架，目录、翻页、跳页、搜索和状态保存均可使用。 |
| 导入后将原文件改名，再从书架移除小说 | 改名后仍可从书架打开副本。移除后书架条目和副本消失，原文件保留。 |
| 打开含章节标题和无章节标题的 TXT | 前者可通过目录跳转。后者仍可正常阅读、跳页和搜索。 |
| 在两种模式中单击正文，再用方向键翻页 | 单击翻到下一页。有焦点时方向键分别向前和向后翻页。将焦点切到其他应用后，按方向键不会翻动小说。 |
| 阅读中拖窄窗口，再放大 | 正文重新换行和分页，调整前的阅读位置仍在视野中。 |
| 搜索出现在其他章节的词语并点击结果 | 搜索能找到其他章节中的命中项，点击后显示对应正文并高亮命中文字。 |
| 切换至极简模式，将背景和边框分别调至完全透明 | 只显示正文，正文仍清晰。浮窗可置顶、移动、缩放，且仍可单击正文翻页。 |
| 以普通模式和极简模式分别退出后重启 | 两次都恢复对应模式、小说和阅读位置。极简模式直接恢复浮窗和已保存的窗口设置。 |
